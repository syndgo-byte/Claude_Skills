# token-audit

로컬 대화 기록(`~/.claude/projects`)을 읽어 **무엇이 토큰을 썼는지** 보여줍니다. 외부 전송 없음, 모델 호출 없음(토큰 0).

```bash
node token-audit.js            # 최근 14일
node token-audit.js --days 30
```

결과는 화면에 출력되고 현재 폴더에 `token-audit-YYYY-MM-DD.md`로도 저장됩니다.

## 보는 법
1. **모델별 실제 사용량**: API가 기록한 정확한 값입니다.
2. **무엇이 맥락을 채웠나**: 훅 출력, 스킬 목록, 스킬 본문, 파일, 도구 결과 등 항목별로 보여줍니다. 한 번 들어간 내용은 이후 매 호출마다 다시 읽히므로 "크기 × 이후 호출 수"로 누적 비용을 추정합니다. **비중이 큰 항목이 범인입니다.**
   - `훅 출력`이나 `시스템 알림`의 횟수가 턴 수만큼 많으면, 매 질문마다 텍스트를 주입하는 훅이 있다는 뜻입니다.
   - `시스템 프롬프트·도구·MCP 정의 (역산)`이 크면 MCP 서버나 플러그인이 도구를 많이 등록한 것입니다.
   - `스킬 본문 로드`가 크면 무거운 스킬이 한 번 불려서 그 세션 내내 다시 읽힌 것입니다.
3. **가장 많이 쓴 세션**: 세션별 정확한 입력·출력 합계입니다.
4. **날짜별 시작 맥락**: 이 값이 갑자기 커진 날이 있다면, 그날 설치한 플러그인이나 스킬이 원인일 가능성이 큽니다.

항목별 토큰은 글자 수로 추정한 값이라 ±30% 정도 오차가 있을 수 있습니다. 순위를 비교하는 용도로 보세요.
